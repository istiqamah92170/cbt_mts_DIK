Branding Integrity Lock menyisipkan watermark di 6 lokasi berbeda dan melakukan pengecekan setiap 5 detik. Jika nama brand atau identitas diubah, peringatan merah muncul di atas aplikasi secara otomatis.
📋 6 Lokasi Watermark 1. CSS comment di dalam :root
2. CSS variable tersembunyi (--_wm-id)
3. Atribut data-wm di body tag
4. Meta tag tersembunyi di head
5. Zero-width karakter di judul aplikasi
6. Comment di akhir setiap blok style
