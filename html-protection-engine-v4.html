🔐 Pendekatan Proteksi v4 Engine ini menggunakan proteksi berlapis tanpa enkripsi body:

• Obfuskasi JS — string di dalam script dipecah ke unicode array, sangat sulit dibaca
• Watermark digital — ID unik + timestamp sebagai bukti kepemilikan hukum
• Anti-inspect — blokir DevTools dan destruksi halaman jika dibuka
• Fingerprinting — rekam siapa yang membuka file

Enkripsi body tidak digunakan karena menyebabkan aplikasi tidak berfungsi — ini keputusan teknis yang benar untuk aplikasi CBT.
📋 Perlindungan hukum Watermark ID unik + timestamp yang disisipkan engine ini berfungsi sebagai bukti kepemilikan digital yang dapat digunakan dalam sengketa hak cipta. Daftarkan juga ke DJKI (djki.go.id) untuk perlindungan hukum penuh.
