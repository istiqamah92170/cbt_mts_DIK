Cara penggunaan 1. Upload file HTML kamu di sini.
2. Tab Proteksi — atur opsi, password, lisensi, lalu unduh file terlindungi.
3. Tab Dekripsi — buka kunci file protected menggunakan password yang sama.

⚠ Simpan selalu file asli (sebelum diproteksi) sebagai backup master.
🔐 Enkripsi v4 — AES-256-GCM Engine ini kini menggunakan Web Crypto API (AES-GCM 256-bit) dengan PBKDF2 key derivation — standar enkripsi militer yang sama digunakan di aplikasi perbankan dan VPN. Password tidak pernah tersimpan dalam bentuk teks di file hasil.
📲 Kompatibel PWA Converter Engine v2 Jika file HTML kamu sudah dikonversi ke PWA menggunakan PWA Converter Engine v2, engine ini akan otomatis mendeteksi dan memindahkan script service worker (data-pwa-converter) dari <body> ke <head> sebelum enkripsi — tanpa perlu edit manual apapun.
